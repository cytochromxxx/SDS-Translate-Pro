# SDS Translate Pro

Flask-based web application for translating Safety Data Sheets (SDS).

## Features
- XML (SDScom) import
- PDF + XML combined import
- JSON (Datalab) import
- HTML template rendering with Jinja2
- Multi-language translation via SQLite phrase database
- PDF / HTML / DOCX export

## Setup

```bash
pip install -r requirements.txt
python app.py
```

App runs on http://localhost:5000
